## 5. Safety Radar — измеренное опережение

| Метрика | Значение |
|---|---|
| WARNING (реальное видео) | 5.8058 с |
| CRITICAL | 6.6066 с |
| Подтверждение инцидента | 7.2072 с |
| **Lead time (WARNING → CRITICAL)** | **0.8008 с** |
| Lead time (browser E2E, 6 FPS) | **0.8342 с** |
| Прогноз пересечения | точка на **ближайшей** границе, не центр |
| Точность прогноза (пример) | `[0.62, 0.889]` при границе x=0.62 |

Проверенные свойства:
- безопасный проход → 0 предупреждений, 0 инцидентов;
- вход → WARNING → CRITICAL → **1 инцидент**;
- повторный вход (U-образная зона) → 2 разных episode_id → 2 инцидента;
- две именованные зоны → по одному инциденту в каждой;
- параллельное движение → без ложного WARNING;
- остановка перед границей → предупреждение снимается;
- потеря наблюдения → UNKNOWN (не ложный NORMAL).
