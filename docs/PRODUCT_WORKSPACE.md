# Рабочее пространство оператора

Обновление 24 октября 2026. Интерфейс для одного локального оператора:
тёмная и светлая монохромные темы, скруглённые карточки и локальный шрифт
Manrope с кириллицей. Собственная компоновка приложения: одна боковая
навигация, свободная рабочая область и подробности по запросу. Узкая рельса,
редакторские вкладки и нижняя строка состояния убраны. Метрики доступны
в «Система» → «Техническая диагностика».

## Основной путь

| Задача оператора | Действие |
|---|---|
| Первый запуск | «Подключить первую камеру» → источник → проверки → «Начать наблюдение» |
| Выбрать рабочую зону | Карточка на «Наблюдении» или раскрываемый быстрый список камер |
| Освободить место | Ctrl/⌘ B скрывает боковую навигацию; F разворачивает наблюдение |
| Проверить человека | «Люди» → СИЗ и возраст последнего наблюдения; детали модели раскрываются отдельно |
| Проверить прогноз | «Радар» → текущие риски, предупреждения и отдельное видео каждого события |
| Задать опасную область | «Обозначить зону» → три или больше точек → название → сохранить |
| Изменить правила | «Камеры» → «Основное и проверки»; изменения сохраняются явно |
| Разобрать нарушение | «Инциденты» → событие → снимок/видео → решение оператора |
| Передать историю | Фильтры → «Скачать CSV»; вся выборка, не только открытая страница |
| Проверить готовность | «Система»; профилирование и отдельные FPS в раскрываемой диагностике |
| Подключить телефон | «Камеры» → «Подключение» → одноразовый QR; штатный LAN/HTTPS запуск обязателен |

Первый запуск не показывает пустые KPI. Во время наблюдения настройки,
таблица истории и диагностика не занимают постоянное место. На телефоне
разделы находятся снизу, подробности инцидента занимают весь экран.
На узком экране дополнительная навигация открывается отдельной панелью.

## Что означает состояние

Нет связи, остановка, ошибка источника, отсутствие свежего кадра и недостаточные
данные не показываются как безопасность. Радар различает приближение и вход.
CRITICAL остаётся заметным до временного подтверждения инцидента.
Проверка завершения нарушения сохраняет тревожное состояние.

Решение «Подтвердить нарушение» — оценка оператора. Оно не завершает физический
эпизод. Прерванное наблюдение не означает, что нарушение устранено. Номер
сотрудника обозначает трек в сеансе, не установленную личность.

Настройки защищены от случайного ухода, включая кнопку браузера «Назад».
Модальные окна поддерживают Tab, Shift Tab, Escape и возврат фокуса.
Зоны поддерживают перетаскивание точек, стрелки и отмену последней точки.
Ошибки источника, загрузки, журнала и доказательства показаны рядом с действием.
Неудачное обновление журнала не выдаётся за отсутствие инцидентов или провал
уже выполненного сохранения настроек.

## Проверка реализации

- 247 Python-тестов прошли, 4 аппаратных/опциональных теста пропущены.
- 38 frontend-тестов; TypeScript и production build проходят.
- Контролируемый AMQP: 17 тестов, включая 60-секундный прогон, перестановку
  ответов, таймаут, восстановление и ограничение параллелизма. Это не LinQ worker.
- `e2e/test_workspace.py`: реальный backend/ONNX, имитированная веб-камера;
  мастер подключения, смена тем, панели, зоны, несохранённые настройки, история,
  мобильный экран. Такой источник не проверяет точность детекции людей.
- `e2e/test_phone_flow.py`: имитированная камера телефона, настоящий обмен
  pairing-кода, локальный ONNX, остановка и отзыв токена.
- `e2e/test_incident_review.py`: отдельная временная база и явно подписанные
  тестовые инциденты; H.264 воспроизведение, снимок, решения, CSV и отказ журнала.
  Тест не добавляет демонстрационные инциденты в рабочую базу.

## Границы готовности

Это приложение для демонстрации полного рабочего пути и локального пилота.
Гарантию промышленной эксплуатации, требуемую точность на конкретной площадке,
физические IP-камеры/телефоны, многопользовательские роли, SSO, резервное
копирование и подписанный установщик эта проверка не устанавливает.

Реальные 5 FPS LinQ не доказаны. В среде нет настроенного endpoint, VPN или
учётных данных ускорителя; конкурентность по умолчанию остаётся 1. Исторические
замеры и новый контролируемый тест разделены в
[LINQ_5FPS_BENCHMARK.md](LINQ_5FPS_BENCHMARK.md).

GitHub Actions у `d587ecf` остановился до запуска job из-за billing/spending limit.
Локальные тесты не заменяют зелёный hosted CI.
